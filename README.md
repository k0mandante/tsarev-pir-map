# Царёв пир — интерактивная карта

Полноэкранная карта для сайта «Царёв пир»: место проведения, метро «Кленовый бульвар» и парковки рядом с парком «Коломенское». Светлая кремовая палитра, плоские здания и собственные SVG-маркеры.

**Краткое описание для поля About в GitHub:**

> Интерактивная карта «Царёв пир» с SVG-маркерами, метро и парковками у Коломенского. MapLibre + OpenFreeMap, без API-ключа, готова к встраиванию через iframe.

## Возможности

- Основная локация: `55.67562617568792, 37.67398563110034`.
- При открытии маркер «Царёв пир» расположен по центру карты.
- SVG-маркеры события, метро и парковок включены в комплект.
- Масштабирование и кнопка возврата к основной точке.
- Карточки объектов со ссылкой на маршрут в Яндекс Картах.
- Плоская карта без 3D-зданий и наклона.
- Без панели настроек и зависимости от сохранённых настроек браузера.

## Структура

```text
dist/
  index.html          Страница карты
  style.css           Оформление
  app.js              Логика, координаты и маркеры
  base-style.json     Основа картографического стиля
  parking-osm.json    Снимок парковок и станции метро из OSM
  icons/
    logo.svg          Царёв пир
    metro.svg         Метро
    parking.svg       Парковки
README.md             Эта инструкция
```

Папка `.openai/` относится к предпросмотру в Sites и не нужна на вашем хостинге. `osm-source.xml` — исходные данные OSM, для работы страницы не требуется.

## Размещение на своём сайте

1. Скачайте репозиторий или архив.
2. Создайте на хостинге папку `/map/`.
3. Загрузите в неё **содержимое `dist/`**, сохранив вложенную папку `icons/`. В готовом архиве файлы страницы уже лежат в корне — загружайте их непосредственно в `/map/`.
4. Проверьте, что `https://ваш-домен.ru/map/index.html` открывает карту.
5. Добавьте iframe в нужный блок сайта.

Node.js, установка пакетов, сборка и серверная часть для размещения не нужны. Используйте HTTP/HTTPS-сервер: открытие `index.html` двойным щелчком через `file://` не подходит из-за загрузки JSON через fetch.

## Встраивание на весь экран

```html
<iframe
  src="/map/index.html"
  title="Как добраться — Царёв пир"
  style="display:block;width:100%;height:100vh;height:100dvh;border:0;"
  loading="lazy">
</iframe>
```

`100dvh` задаёт высоту видимой области экрана, в том числе на телефоне. Ширина iframe ограничена родительским блоком: для карты на всю ширину страницы уберите у этого блока ограничения ширины и боковые отступы.

Для блока фиксированной высоты замените `height:100vh;height:100dvh;` на `height:600px;`.

Для карты на другом домене используйте полный **публичный** адрес в `src`. Закрытый предпросмотр Sites не подходит для посетителей вашего сайта. Хостинг карты должен разрешать встраивание: заголовки `X-Frame-Options` и CSP `frame-ancestors` не должны запрещать ваш домен.

## Публикация через GitHub Pages

Для простой статической публикации без сборки:

1. Создайте репозиторий и загрузите **содержимое `dist/` в его корень**. `index.html` должен лежать в корне, рядом с `app.js`, `style.css`, JSON-файлами и папкой `icons/`.
2. Добавьте этот `README.md` в корень репозитория.
3. В настройках репозитория откройте **Pages** и выберите публикацию из ветки, например `main`, папка `/ (root)`.
4. Используйте URL, который GitHub покажет после публикации, как `src` вашего iframe.

Если храните проект с исходной структурой `dist/`, публикуйте эту папку средствами своего хостинга или отдельным процессом развёртывания. Простая публикация GitHub Pages из корня сама не перенесёт туда содержимое `dist/`.

## Как менять карту

### Координаты события

В начале `dist/app.js` измените `VENUE`. В коде порядок **долгота, широта**:

```js
VENUE = [37.67398563110034, 55.67562617568792]
```

Это фрагмент существующего объявления: замените значения в нём, не добавляйте второе объявление переменной. Центр карты и ссылка на маршрут используют эти координаты.

### SVG-маркеры

Замените файлы в `dist/icons/`, сохранив имена `logo.svg`, `metro.svg` и `parking.svg`. Рекомендуются автономные SVG с `viewBox`, без внешних изображений и шрифтов.

Базовый размер в `prefs.size` — **64 px**. Сохранены пропорции: маркер события — 64 px, метро — 40 px, парковки — 32 px. Размеры не меняются при масштабировании карты.

### Цвета и масштаб

Стили интерфейса находятся в `dist/style.css`. Цвета картографических слоёв и зданий задаются в `dist/app.js`; начальный масштаб — параметр `zoom` при создании `maplibregl.Map`.

После правок загрузите изменённые файлы на хостинг. Если браузер показывает старую версию, обновите страницу с очисткой кеша.

## Данные и зависимости

- Отрисовка: [MapLibre GL JS](https://maplibre.org/), версия 5.6.1, лицензия BSD-3-Clause.
- Картографическая основа: [OpenFreeMap](https://openfreemap.org/).
- Данные: [OpenStreetMap](https://www.openstreetmap.org/copyright), ODbL.
- Парковки и станция метро: снимок OSM от **27.10.2026**. Частные и закрытые парковки отфильтрованы по тегам OSM; свободные места не отслеживаются. Доступ и тарифы уточняйте на месте.

Платный API-ключ не используется. Карта требует подключения к интернету: библиотека и тайлы загружаются с внешних сервисов. Условия и стоимость выбранного вами хостинга определяются отдельно.

**Сохраняйте атрибуцию MapLibre, OpenFreeMap и OpenStreetMap внизу карты.** SVG-маркеры предоставлены владельцем проекта; их права не определяются лицензиями картографических библиотек.
